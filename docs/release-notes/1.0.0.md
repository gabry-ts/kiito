# Kiito 1.0.0

Kiito is now signed with a Developer ID certificate and notarized by Apple. That means no more Gatekeeper warnings on first launch and no more removing the quarantine flag by hand. Just open the app.

This release also adds automatic updates. Kiito checks for new versions using Sparkle and will ask, the second time you launch it, whether it should check automatically from then on. You can also trigger a check any time from the menu bar ("Check for Updates…") or from Settings, and toggle automatic checks there too.

The app is now a universal binary, running natively on both Apple Silicon and Intel Macs.

There's also a new "Buy Me a Coffee…" link in the menu bar and in Settings, for anyone who wants to support the project.

## If you're updating from an older version

Versions before 1.0.0 have no updater, so Sparkle can't reach them. You'll need to download 1.0.0 from the Releases page and install it manually, the same way you installed Kiito before. After that, every future update installs itself automatically.

Switching to a Developer ID signature also changes Kiito's code signature, which invalidates the Accessibility permission you granted to the old build. After installing 1.0.0, open **System Settings > Privacy & Security > Accessibility** and turn Kiito back on. If it's already listed but greyed out or not working, remove it from the list first with the minus button, then relaunch Kiito and grant access again when it asks. This is a one-time step: every future update ships with the same Developer ID signature, so the grant will keep working from here on.
