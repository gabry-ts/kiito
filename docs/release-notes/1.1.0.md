# Kiito 1.1.0

Kiito now shares one design with Tuuli, Kaiku, Mittari and Kello, and the menu bar menu is now a popover. From it you can turn Kiito on and off, pick the trigger button, the speed and the profile, and reach Settings, updates and Buy Me a Coffee. The menu bar icon is a new glyph drawn from the ball in the app icon.

Settings uses the shared window with a sidebar. Using, duplicating, renaming and deleting a profile now happens from the profile's own page, and the updates switch and the version moved to About.

Scrolling works exactly as before, and the Accessibility permission you already granted stays in place.
